# Single_Pages 单页工坊

一个轻量级的静态页面托管平台，支持用户注册、项目管理、文件编辑、免登录部署、访客项目管理、会员组、余额充值、在线退款等功能。

## 功能特性

### 用户功能
- 用户注册/登录（邮箱验证码、手机验证码、账号密码，跟随后台配置）
- 项目创建与管理（项目数限制）
- 在线文件编辑器（支持HTML/CSS/JS）
- ZIP打包上传/下载
- 专属背景颜色自定义
- 用户组系统（免费/付费/永久用户组）
- 购买用户组（易支付对接，支付宝/微信/QQ）
- 余额充值（自定义金额、快捷金额、最低充值限制）
- 订单查询（订单号、商品、金额、支付方式、时间）
- 在线退款（微信/支付宝收款，阶梯扣费）
- 模板市场（浏览/购买项目模板）
- 登录日志、个人中心

### 访客功能
- 免登录部署静态页面
- 访客项目管理（密钥验证）
- 项目直接访问（/{pro_id}）

### 首页模板
- 模板系统（/templates/ 目录，支持多模板切换）
- 内置默认模板和MV蓝色主题模板
- 后台在线编辑模板文件
- 模板信息自动同步站点名称、简介、备案号、套餐

### 后台管理
- 仪表盘（用户/项目/文件统计、趋势图表）
- 用户管理（增删改查、设置用户组、修改配额）
- 用户组管理（增删改查、设默认、售卖设置、永久/限时）
- 项目管理（用户项目/访客项目、文件查看、直接跳转）
- 模板管理（项目模板CRUD、模板文件在线编辑）
- 首页模板管理（切换/编辑）
- 订单管理（全部订单、统计、手动标记已付/取消支付，含续费叠加逻辑）
- 退款管理（审核、同意/拒绝、删除记录）
- 公告管理（前台展示）
- 邮箱通知（群发邮件）
- 内容配置（FAQ、快速开始、功能说明）
- 网站配置（基本/邮件/短信/支付/安全/充值退款 六个子页面）
- 登录日志、系统信息、在线升级

## 技术栈
- PHP 8.2+（最低7.4）
- MySQL 5.7+
- 原生CSS + Remix Icon
- Chart.js

## 安装部署

1. 将代码上传到网站根目录
2. 访问 `/install/` 进行安装
3. 配置数据库信息
4. 安装完成后删除 `/install/` 目录或保留 `install.lock`

### Nginx配置
```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /www/wwwroot/your-domain;
    index index.php index.html;
    
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    
    location ~ \.php$ {
        fastcgi_pass unix:/tmp/php-cgi-82.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```

## 目录结构
```
├── admin/              # 后台管理
├── users/              # 用户中心
├── templates/          # 首页模板目录
├── assets/             # 静态资源（图标等）
├── install/            # 安装程序
├── functions.php       # 核心函数库
├── config.php          # 配置文件（安装后生成）
├── style.css           # 全局样式
├── pay_notify.php      # 支付异步回调
├── pay_return.php      # 支付同步回调
├── deploy.php          # 免登录部署
├── help.php            # 帮助中心
└── README.md
```

  - 支付回调同样支持续费叠加逻辑
